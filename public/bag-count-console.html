Getting it into the repo
  1. Collectors upload from this page — no GitHub account or token needed.
  2. You run the sync script to pull everything into detector-service/dataset/raw/.
  3. Review, commit, then label the side photos on the Label tab.
cd detector-service
python sync_training_data.py --api https://white-meadow-0dc31e50f.7.azurestaticapps.net
# -> dataset/raw/<pallet>/{FRONT,RIGHT,BACK,LEFT,FLAP_1}.jpg
# -> dataset/raw/samples.csv   (the ground-truth counts)

Training configuration
Dataset not ready. Add images and label every visible sewn flap.
  1. Export COCO and place the JSON plus images in detector-service/dataset/{train,valid,test}/. Split by pallet, not by photo.
  2. Push the dataset branch, then run the Train RF-DETR GitHub Action. It uploads the best checkpoint and evaluation JSON as artifacts.
  3. Use a GPU-backed runner for a production run. The action requires 20+ images per split and enforces the held-out accuracy gate.
cd detector-service
pip install -r requirements.txt -r requirements-rfdetr.txt
python train.py --dataset-dir ./dataset --model-size small --epochs 100 --batch-size 4
# -> output/checkpoint_best.pth
# set RFDETR_MODEL_SIZE=small, RFDETR_WEIGHTS and RFDETR_CLASS_NAMES=bag_flap
